# --style

Ask art-director to instantiate stylized-3d: palette, materials, lighting, world
scale, silhouette vocabulary, geometry/texture budgets and animation language.
Create style-bible.json and a small reference sheet using supplied references,
native image tools or Blender concept previews. Record generated-image provenance.
Present actual references for STYLE LOCK approval. Once approved, run style-lock.sh
--lock and quote the JSON. Existing approval of unchanged references persists.
Then file mesh cards with required clips, metric bounds and collision policy.
Output one STYLE block: BIBLE, REFERENCES, APPROVAL, LOCK_JSON, ART_CARDS.

# --design

Use game-designer for the selected genre's loop, movement, combat, encounters,
resource economy, audio/visual feedback, UI and restart behavior. Quantify pure
rules and physics scenario tolerances separately. Write design/content documents
and file SPEC/ART cards. Record the asset/animation/audio cost. For a whole game,
use the build workflow to stage work rather than demand a separate prompt per
mechanic. Return one DESIGN RUN block: DOCS, CONTENT, FEEL_TARGETS, ART_COST,
SCENARIOS, FILED, OPEN_QUESTIONS. Design is not an implementation pass.

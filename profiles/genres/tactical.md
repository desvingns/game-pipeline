# Tactical FPS

Prioritize precise mouse look, consistent aim, movement accuracy penalties,
recoil/spread, reload timing, cover, sightlines, footstep feedback and objective
clarity. Specify round states, teams, buy/loadout rules only when the brief needs
them. Test hit/miss/occlusion, moving vs stationary accuracy, reload interruption,
round reset and spawn safety. Offline bots do not imply network multiplayer.

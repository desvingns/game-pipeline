# --art

Take one ART card (--next uses the art backlog). Verify STYLE LOCK. Use
art-prompter to author a mesh spec/recipe and build via mesh-build.sh. Inspect
all three previews; art-director reviews against the references. Fix the recipe
and rebuild if needed, preserving attempts. Asset-integrator wraps the GLB in
Godot and verifies real scale, collision, materials, animation and reachability.
Validate all resulting assets and capture a real runtime view. File other needs
as separate cards. Return one ART RUN block: CARD, RECIPE, BUILD_JSON,
PREVIEWS, REVIEW, INTEGRATION, RUNTIME_EVIDENCE, GAPS.

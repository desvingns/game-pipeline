description: Codex discovery, generated adapters and validation boundaries
---

- Codex entry points are skills, not renamed Claude command directories.
  Personal `gp-dev` locates this generator; each generated game has a project
  skill plus `AGENTS.md`, Markdown roles and thin native TOML adapters.
- Native role adapters inherit model settings. Named-agent fallback dispatches
  the canonical role body through available collaboration tools.
- Verify discovery using the local Codex app-server `skills/list`; parsing a
  Markdown file alone does not prove the installed client sees it.
- `codex-native` renders the prompt in Bash/Python, then the host agent calls its
  available image tool and registers the result. External-file fallback remains;
  human STYLE LOCK approval is unchanged.
- Regression gates use an explicit fake engine. They do not prove a real Godot
  build/export, rendered screenshot, Android device run or native agent workflow.
